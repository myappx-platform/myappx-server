MyAppx Desktop 更新日志

本页由 AppxServer 本地提供，供桌面客户端「查看更新日志」及升级前参考使用。

当前发布版本：6.2.1

升级指南

升级前必读

无论应用内升级还是手动安装，请先完全退出 MyAppx Desktop。若客户端仍在运行，安装程序可能因文件占用而失败。

请勿在应用仍在运行时执行安装程序（setup.exe）。

方式一：应用内升级（推荐）

  1. 收到新版本通知后，点击 Download Update 下载安装包。
  2. 下载完成后，选择 Restart and install。
  3. 应用退出后启动安装程序完成升级。

方式二：手动升级

  1. 通过菜单 File → Quit 或托盘图标退出应用。
  2. 运行新版本安装程序（可从 /desktop 目录获取）。

异常退出后的恢复

若上次因崩溃、强制结束或断电而异常退出，直接重新启动桌面客户端即可。

更新清单由 latest.yml 提供；安装包与 blockmap 文件需与清单一并部署到 AppxServer 的 desktop/ 目录。

版本历史

6.2.1 2026-06-14 Latest
  • 改进 桌面文档与更新链接统一为可配置的 MYAPPX_DESKTOP_BASE_URL，默认指向本地 AppxServer /desktop 路径。
  • 改进 「View Changelog」等帮助链接改为从 AppxServer 加载本页，便于离线/内网环境查看更新说明。
  • 修复 部分外部链接配置中的 URL 拼写错误。

管理员：发布新版本

  1. 在开发机构建安装包：npm run package:windows-installers
  2. 将生成的 myappx-desktop-setup-x.y.z-win.exe、.blockmap 及 latest.yml 复制到 AppxServer 的 desktop/ 目录。
  3. 更新本页「当前发布版本」与各版本说明（可选）。
  4. 客户端下次检查更新时将拉取新的 latest.yml。
