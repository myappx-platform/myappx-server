My Desktop

My Desktop 桌面客户端将 My Workspace 工作区封装为原生 Windows 应用，连接已运行的 MyAppx Server（AppxServer）， 支持应用内自动更新与内网分发。

产品说明

主要特性

  • 原生桌面窗口、系统托盘与通知
  • 连接外部 MyAppx Server
  • 本地服务器请求自动注入预认证头
  • 应用内检查更新

系统要求

  • Windows 10 / 11（64 位）
  • 约 150 MB 磁盘空间（客户端）
  • 已部署并可访问的 MyAppx Server
  • 安装需管理员权限（NSIS 安装程序）

升级指南

升级前必读

无论应用内升级还是手动安装，请先完全退出 My Desktop。若客户端仍在运行，安装程序可能因文件占用而失败。

请勿在应用仍在运行时执行安装程序（setup.exe）。

方式一：应用内升级（推荐）

  1. 收到新版本通知后，点击 Download Update 下载安装包。
  2. 下载完成后，选择 Restart and install。
  3. 应用退出后启动安装程序完成升级。

方式二：手动升级

  1. 通过菜单 File → Quit 或托盘图标退出应用。
  2. 运行新版本安装程序（可从 /desktop 目录获取）。
